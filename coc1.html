CSS NC II · COC 01

Install and Configure Computer Systems

Review material for this Certificate of Competency. Use the sections below to recall the standards, procedures, and tools you'll need for assessment — this is a review aid, not a lesson.

Competency Standards TESDA TR

ElementDescription
1.1Assemble computer hardware
Assemble a computer unit following the correct sequence, ESD precautions, and manufacturer guidelines.
1.2Prepare installer for installation
Prepare bootable installation media and verify system BIOS/UEFI settings prior to OS installation.
1.3Install operating system and drivers
Install the OS and required device drivers for peripherals in accordance with the installation checklist.
1.4Install application software
Install and configure application software based on end-user requirements and software documentation.
1.5Conduct testing and documentation
Test the assembled and configured system and complete the required installation report/checklist.

Procedures

  1. Prepare workstation and check unit specifications against job order
  2. Assemble hardware components following ESD-safe procedures
  3. Configure BIOS/UEFI settings
  4. Install operating system from prepared installer
  5. Install device drivers and verify device manager for errors
  6. Install requested application software
  7. Test system functionality and complete documentation
