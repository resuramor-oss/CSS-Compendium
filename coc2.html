CSS NC II · COC 02

Set Up Computer Networks

Review material for this Certificate of Competency. Use the sections below to recall the standards, procedures, and tools you'll need for assessment — this is a review aid, not a lesson.

Competency Standards TESDA TR

ElementDescription
2.1Install and configure network devices
Install and configure network hardware such as switches, routers, and access points per network design.
2.2Configure computer systems as part of a network
Set up IP addressing, network protocols, and shared resources on client computers.
2.3Inspect and test configured computer networks
Test network connectivity, performance, and security, and document the results.

Procedures

  1. Review network design/layout and requirements
  2. Terminate and crimp UTP cables following T568A/T568B standard
  3. Install and mount network devices (switch, router, access point)
  4. Configure IP addressing scheme (static/DHCP)
  5. Connect and test client devices on the network
  6. Verify connectivity using ping/tracert and document results
