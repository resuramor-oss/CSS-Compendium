This core unit covers setting up computer servers for LANs and SOHO systems. It includes setting up user access, configuring network services, and performing testing, documentation, and pre-deployment procedures.

The focus is a server that is not only installed but **secure, documented, and ready for use**.

## What you must demonstrate

- Create user folders and configure access levels according to network access policy.
- Perform security checks on user access.
- Confirm the server's normal functions, including boot and network connectivity.
- Install or update required modules and add-ons.
- Configure network services based on user and system requirements.
- Test the services and respond to unplanned events.
- Perform pre-deployment procedures, security checks, and documentation.

## Key terms

- **NOS** — network operating system (for example, Windows Server or a Linux server distribution).
- **User account** — an identity used to log in and access resources.
- **Group** — a collection of accounts that share permissions.
- **Least privilege** — giving an account only the access it needs.
- **Domain controller** — a server that authenticates users and stores directory data in a Windows domain.
- **DHCP** — automatically assigns IP addresses.
- **DNS** — resolves names to IP addresses.
- **IIS** — Microsoft's web server role.
- **Pre-deployment** — preparing and checking the server before it is released for use.
