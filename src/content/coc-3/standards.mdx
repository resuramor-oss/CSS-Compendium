| Element | Performance criteria |
| --- | --- |
| **1. Set up user access** | 1.1 Create a user folder in accordance with network operating system (NOS) features. 1.2 Configure user access level based on NOS features and established network access policies/end-user requirements. 1.3 Perform a security check in accordance with established network access policies/end-user requirements. |
| **2. Configure network services** | 2.1 Check normal functions of the server in accordance with manufacturer instructions. 2.2 Install/update required modules or add-ons based on NOS installation procedures. 2.3 Confirm the network services to be configured based on user/system requirements. 2.4 Check the operation of network services based on user/system requirements. 2.5 Respond to unplanned events or conditions in accordance with established procedures. |
| **3. Perform testing, documentation, and pre-deployment procedures** | 3.1 Undertake pre-deployment procedures based on enterprise policies and procedures. 3.2 Undertake operation and security checks based on end-user requirements. 3.3 Prepare and complete reports according to enterprise policies and procedures. |

## Range of variables (selected)

- **Normal functions of a server:** no error on boot sequence; network connectivity.
- **Network services:** remote access, domain controller, web services, database services, proxy server, file/printer and other resource sharing.
- **Pre-deployment procedures:** installation of applications; populating the database.

## Assessment methods

The assessor may select any two of: practical demonstration with oral questioning, interview, or portfolio.

Resources that must be provided include a PC/workstation and server, a network operating system, a network printer, tools and test instruments, and appropriate software applications.
