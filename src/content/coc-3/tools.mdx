### Hardware

- Server or high-spec workstation
- Network switch and patch cables
- Client PC or laptop for testing
- Network printer
- Server cabinet or rack (if available)
- Uninterruptible power supply (UPS)

### Software

- Network operating system (Windows Server or Linux server)
- Required server roles and modules
- DHCP, DNS, web, database, file, and print services as required
- Antivirus/endpoint protection
- Backup and recovery software
- Remote administration tools
- Diagnostic and monitoring utilities

### Tools and testing devices

- Screwdriver set and pliers
- LAN cable tester
- Digital multimeter
- Console cable or KVM access
- Labels and cable ties
- PPE as required

### Documentation

- Network design and IP addressing plan
- Server build checklist
- User account and permission matrix
- Service configuration records
- Test results and pre-deployment report
- Backup and recovery plan
