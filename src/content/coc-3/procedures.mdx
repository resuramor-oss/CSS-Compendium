### A. Prepare the server

1. Review the server role, network design, and user requirements.
2. Confirm the hardware, storage, network connections, and power.
3. Install or verify the network operating system.
4. Set a static IP address or DHCP reservation.
5. Install updates and required drivers.

### B. Set up user access

1. Create user accounts and required groups.
2. Create user folders according to the NOS and policy.
3. Assign access levels based on role and least privilege.
4. Configure share and NTFS permissions.
5. Test access with an authorized account and confirm that an unauthorized account is denied.
6. Review account and security settings.

### C. Configure network services

1. Confirm the services required by the design.
2. Install or update the required modules and add-ons.
3. Configure DHCP, DNS, file/print sharing, web, database, or remote access as required.
4. Start the services and set them to start automatically.
5. Test each service locally and from a client.
6. Review firewall and security settings.
7. Respond to errors according to procedure and document them.

### D. Test and prepare for deployment

1. Reboot the server and confirm that it starts without errors.
2. Confirm network connectivity and service availability.
3. Install required applications.
4. Populate and test the database if applicable.
5. Run operation and security checks.
6. Confirm backups and recovery procedures.
7. Complete the pre-deployment checklist and reports.
8. Obtain sign-off before release.
