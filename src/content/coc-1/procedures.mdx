### A. Plan and prepare

1. Read the job order and confirm the unit specification and client requirements.
2. Prepare the workspace and apply OHS and ESD precautions.
3. Identify the tools, equipment, and testing devices needed, and check that they are safe and working.
4. Inspect the components and confirm that all required materials are present.
5. Back up existing data if the unit is not new.

### B. Assemble the hardware

1. Open the case and install the power supply if it is not pre-installed.
2. Install the CPU into the socket, aligning the notch and triangle.
3. Apply a thin, even layer of thermal paste and mount the CPU cooler.
4. Install the RAM in the correct slots until the clips lock.
5. Install the motherboard on the standoffs and secure it.
6. Install the storage drives and connect SATA or NVMe connections.
7. Install the GPU and connect any required auxiliary power.
8. Connect front-panel headers, fans, and power cables.
9. Inspect all connections, close the case, and connect the peripherals.

### C. Configure firmware and install the OS

1. Power on and enter BIOS/UEFI.
2. Confirm that the CPU, RAM, and storage are detected.
3. Configure the date/time, boot order, and any required hardware settings.
4. Save and exit, then boot from the prepared installer.
5. Select the installation language, time, and keyboard settings.
6. Partition and format the target drive after confirming the backup.
7. Complete the OS installation and first-boot setup.
8. Install OS updates and restart as required.

### D. Install drivers and applications

1. Identify unknown or missing devices.
2. Install the chipset, network, audio, and graphics drivers.
3. Confirm that Device Manager shows no warnings.
4. Install the applications required by the client.
5. Apply application and driver updates.
6. Configure the applications and verify that they launch correctly.

### E. Test, clean up, and document

1. Run POST and confirm that the system boots normally.
2. Test the display, audio, network, USB ports, and input devices.
3. Run a stress test on the processor, GPU, memory, and disk.
4. Record temperatures, errors, and any anomalies.
5. Clean the workspace and dispose of waste according to 5S and 3Rs.
6. Complete the installation/test report and forward it to the appropriate personnel.
