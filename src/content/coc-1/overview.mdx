This core unit covers the outcomes required to install and configure desktop and workstation computer systems. It is assessed through practical demonstration with oral questioning, an interview, or a portfolio.

The assessment is not only about making the computer turn on. You are expected to:

- plan and prepare assembly work with occupational health and safety (OHS) in mind;
- identify and check the materials, tools, and testing devices needed;
- assemble the hardware correctly;
- configure BIOS/UEFI;
- prepare a bootable installer;
- install the operating system, drivers, updates, and application software;
- test the system, including a stress test; and
- complete the required documentation.

> **Assessment reminder.** The assessor may ask you to explain *why* you performed a step, not just whether the unit booted. Be ready to justify component choices, safety practices, and test results.

## What "competent" looks like

| Element | What you must demonstrate |
| --- | --- |
| 1. Assemble computer hardware | Plan the work, prepare tools and materials, assemble the unit, and configure BIOS. |
| 2. Prepare installer | Create a bootable device and prepare the installer according to the software guide and license. |
| 3. Install OS and drivers | Install the operating system, device drivers, and updates, checking quality as you go. |
| 4. Install application software | Install applications based on user requirements and license terms; apply updates. |
| 5. Test and document | Test the installation, run a stress test, observe 5S and 3Rs, and submit documentation. |

## Key terms

- **POST** — Power-On Self-Test; firmware checks basic hardware before booting.
- **BIOS/UEFI** — firmware that initializes hardware and chooses the boot device.
- **Driver** — software that lets the operating system communicate with a device.
- **Stress test** — sustained load used to check stability and reliability.
- **5S** — Sort, Set in order, Shine, Standardize, Sustain.
- **3Rs** — Reduce, Reuse, Recycle/Recover.
