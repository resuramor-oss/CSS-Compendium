The table below summarises the official elements and performance criteria. Italicised terms in the TR are elaborated in its Range of Variables; the wording here is condensed for review.

| Element | Performance criteria |
| --- | --- |
| **1. Assemble computer hardware** | 1.1 Plan and prepare unit assembly to ensure OHS policies and procedures are followed in accordance with systems requirements. 1.2 Identify and obtain materials necessary to complete the work, checked against systems requirements. 1.3 Obtain tools, equipment, and testing devices; check for correct operation and safety. 1.4 Assemble computer hardware in accordance with established procedures and systems requirements. 1.5 Perform BIOS configuration in accordance with hardware requirements. |
| **2. Prepare installer** | 2.1 Create portable bootable devices in accordance with software manufacturer instructions. 2.2 Prepare customised installers in accordance with the software utilisation guide and end-user agreement. 2.3 Carry out installation of portable applications in accordance with the software user guide and software licence. |
| **3. Install operating system and drivers for peripherals/devices** | 3.1 Install the OS in accordance with established installation procedures and end-user requirements. 3.2 Install and configure peripheral/device drivers in accordance with manufacturer instructions and/or OS installation procedures. 3.3 Access and install OS and driver updates/patches in accordance with manufacturer recommendations and requirements. 3.4 Undertake ongoing checks of the quality of the work in accordance with established procedures. |
| **4. Install application software** | 4.1 Install application software based on software installation guides, end-user requirements, and the software licence agreement. 4.2 Carry out variations to application software installation according to customer/client requirements. 4.3 Access and install software updates in accordance with manufacturer recommendations and requirements. |
| **5. Conduct testing and documentation** | 5.1 Test devices/systems and/or installation to determine whether it conforms to requirements. 5.2 Conduct a stress test to ensure reliability of equipment in accordance with manufacturer instructions and system requirements. 5.3 Follow 5S and 3Rs according to environmental policies. 5.4 Forward documentation in relation to the test to appropriate personnel and/or authority in accordance with requirements. |

## Range of variables (selected)

- **Tools and testing devices:** protective eyewear, digital multimeter, wire stripper with bolt cutter, pliers, screwdrivers, soldering iron, desoldering tool, anti-static wrist wrap, Allen wrench, flashlight, LAN tester, crimping tools, IC insertion/extraction tools, tweezers, mirror.
- **Computer hardware:** motherboard, hard disk, memory modules, video card, sound card, power supply, optical disc drives, cables and cords.
- **Operating systems:** Windows, macOS, Linux.
- **Installation methods:** automatic, custom, optical device, portable device, network.
- **Peripherals/devices:** printer, scanner, interface cards (TV tuner, video card, sound card).
- **Application software:** productivity tools, utilities (anti-virus, virtualisation, disk management, optical disc burning), games.
- **Stress test covers:** processor, video card, memory, hard disk.

## Assessment methods

The assessor may select any two of:

1. Practical demonstration with oral questioning
2. Interview
3. Portfolio

The following resources must be provided: tools and test instruments, a PC or workstation, computer peripherals/devices, and appropriate OS, drivers, and software applications.
