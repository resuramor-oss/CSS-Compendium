### Tools

- Crimping tool
- Punch-down tool
- Wire stripper with bolt cutter
- Pliers (assorted)
- Screwdriver set
- LAN cable tester
- Digital multimeter
- Utility knife
- Cable ties and labels
- Flashlight

### Equipment

- Router, switch, and wireless access point or repeater
- Desktop or laptop clients
- Network printer and network storage (if required)
- Patch panel and keystone jacks
- Cable raceway, conduit, and mounting hardware
- Protective eyewear, gloves, and working clothes

### Materials

- UTP copper cable (Cat5e/Cat6 as specified)
- RJ45 connectors
- Keystone jacks and faceplates
- Patch cords
- Fiber optic cable and connectors if specified (terminated)
- Cable labels
- Insulators, clamps, and fasteners
- Wireless security credentials and network documentation

> **Tip.** Bring more connectors and cable than the plan requires. A failed crimp should be cut off and redone, not hidden.
