| Element | Performance criteria |
| --- | --- |
| **1. Install network cables** | 1.1 Determine and plan cable routes in accordance with network design and the actual installation site. 1.2 Identify and obtain network materials, checked against systems requirements. 1.3 Obtain tools, equipment, and testing devices; check for correct operation and safety. 1.4 Use appropriate PPE and follow OHS policies and procedures. 1.5 Perform copper cable splicing based on EIA/TIA standards. 1.6 Install network cables and cable raceway in accordance with established procedures and installation requirements. 1.7 Check installation work for unnecessary damage and compliance with requirements. 1.8 Follow OHS standards and 5S principles. 1.9 Dispose of excess components and materials based on WEEE directives and the 3Rs waste management program. |
| **2. Set network configuration** | 2.1 Check network connectivity of each terminal in accordance with network design. 2.2 Diagnose and remedy faults or problems in line with standard operating procedures. 2.3 Configure NIC settings in accordance with network design. 2.4 Carry out communication checking between terminals in accordance with OS network configuration guides. 2.5 Respond to unplanned events or conditions in accordance with established procedures. |
| **3. Set router/Wi-Fi/wireless access point/repeater configuration** | 3.1 Configure client device system settings in accordance with manufacturer instructions and end-user preferences. 3.2 Configure the LAN port in accordance with manufacturer instructions and network design. 3.3 Configure the WAN port in accordance with manufacturer instructions and network design. 3.4 Configure wireless settings in accordance with manufacturer instructions, network design, and end-user preferences. 3.5 Configure security/firewall/advanced settings in accordance with manufacturer instructions and end-user preferences. |
| **4. Inspect and test the configured computer networks** | 4.1 Undertake final inspections to ensure the configuration conforms with the manufacturer instruction/manual. 4.2 Check computer networks to ensure safe operation. 4.3 Prepare and complete reports according to company requirements. |

## Range of variables (selected)

- **Network design:** topology, distribution terminals.
- **Network materials:** copper and fiber cables, terminals, cable raceway/duct, clamps, fasteners, insulators, terminal box.
- **Tools and testing devices:** protective eyewear, digital multimeter, wire stripper with bolt cutter, pliers, screwdrivers, LAN tester, crimping tools.
- **PPE:** gloves, goggles, working clothes.
- **Splicing:** straight-through, cross-talk, roll-over.
- **Network cables:** copper cable, terminated fiber optic cable.
- **Cable raceway:** slotted PVC, metallic raceway, flexible conduit.
- **Client devices:** laptop, desktop, network storage, network printer.
- **Installation requirements:** additional requirements for fiber optic cable installation.

## Assessment methods

The assessor may select any two of: practical demonstration with oral questioning, interview, third party, or portfolio.

Resources that must be provided include a PC or workstation, network cables and materials, a router/Wi-Fi/access point/repeater, tools and test instruments, appropriate software, and PPE.
