This core unit covers setting up computer networks for LANs and small-office/home-office (SOHO) systems. It includes installing network cables, configuring network settings, setting up router/Wi-Fi/access point/repeater configuration, and inspecting and testing the network.

The assessment focuses on a working, documented network that matches a design — not just a cable that passes a tester.

## What you must demonstrate

- Plan cable routes based on the network design and actual site.
- Identify materials, tools, and testing devices and check them for safety.
- Terminate and install copper cables to EIA/TIA standards.
- Configure NICs, IP addressing, and communication between terminals.
- Configure LAN, WAN, wireless, security, and firewall settings on a router or access point.
- Inspect and test the network and complete reports.
- Apply OHS, 5S, 3Rs, and WEEE disposal practices.

## Key terms

- **UTP** — unshielded twisted pair copper cable.
- **T568A / T568B** — pin-out standards for RJ45 connectors.
- **Straight-through cable** — same pin-out on both ends; connects unlike devices.
- **Crossover cable** — transmit and receive pairs swapped; connects similar devices.
- **DHCP** — automatically leases IP addresses to clients.
- **DNS** — resolves names to IP addresses.
- **Default gateway** — the router address used to reach other networks.
- **SSID** — the name of a wireless network.
- **WAN / LAN** — wide area network (ISP side) and local area network (local devices).
