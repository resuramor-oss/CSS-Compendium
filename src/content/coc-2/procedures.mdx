### A. Plan the installation

1. Review the network design, topology, and distribution points.
2. Walk the site and plan cable routes, raceways, and device placement.
3. Identify the required cable length, connectors, jacks, and materials.
4. Prepare tools, testers, and PPE; check that they are safe and working.
5. Identify power and interference hazards along the route.

### B. Terminate and install copper cables

1. Measure and cut the cable, leaving a service loop.
2. Strip the jacket carefully without damaging the conductors.
3. Arrange the conductors according to T568A or T568B.
4. Trim evenly, insert into the RJ45 connector, and crimp.
5. Inspect the connector and test with a LAN tester.
6. Install the cable in the raceway or conduit, avoiding sharp bends and power lines.
7. Label both ends and terminate the patch panel or keystone jack.
8. Re-test every run and record the result.

### C. Configure the client

1. Connect the client to the switch or access point.
2. Check the link status and NIC settings.
3. Configure a static IP or confirm that DHCP has issued a lease.
4. Set the subnet mask, default gateway, and DNS servers.
5. Test communication with the gateway and another terminal.
6. Resolve any addressing or name-resolution fault.

### D. Configure the router or access point

1. Connect to the device's management interface using the correct port.
2. Change the default administrator password.
3. Configure the WAN connection type required by the ISP.
4. Configure the LAN address and DHCP scope.
5. Configure the wireless SSID, band, channel, and security.
6. Configure firewall and advanced settings as required.
7. Save the configuration and reconnect the clients.

### E. Inspect, test, and document

1. Verify that all cables and devices are physically secure.
2. Test wired and wireless connectivity from each client.
3. Confirm internet access, local file sharing, and printer access as required.
4. Test coverage and roaming if an access point or repeater is used.
5. Record the topology, addressing scheme, device configuration, and test results.
6. Clean the site and dispose of waste according to 5S, 3Rs, and WEEE.
7. Submit the completed report.
