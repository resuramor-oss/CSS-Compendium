CSS NC II · COC 03

Set Up Computer Servers

Review material for this Certificate of Competency. Use the sections below to recall the standards, procedures, and tools you'll need for assessment — this is a review aid, not a lesson.

Competency Standards TESDA TR

ElementDescription
3.1Set up user access
Create and configure user accounts, groups, and access permissions on the server.
3.2Configure network services
Install and configure network services such as DNS, DHCP, and file/print sharing.
3.3Perform testing, documentation, and pre-deployment procedures
Test configured services for functionality and complete pre-deployment documentation.

Procedures

  1. Install server operating system
  2. Configure server roles (e.g., DNS, DHCP, file/print server)
  3. Create user accounts, groups, and set access permissions
  4. Configure network services according to specifications
  5. Test each service for correct functionality
  6. Complete pre-deployment checklist and documentation
